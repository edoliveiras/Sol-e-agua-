# SOL & ÁGUA BRASIL

Guia visual de destinos naturais e hospedagens no Brasil, com foco em praias, cachoeiras, hotéis, day-use e pousadas.

## Tecnologias
- React
- TanStack Start / TanStack Router
- TypeScript
- Tailwind CSS
- Vite

## Desenvolvimento
```bash
bun install
bun run dev
```

## Build
```bash
bun run build
```

## Observação sobre os dados
Os destinos atualmente cadastrados são conteúdo demonstrativo. Fotos podem ser ilustrativas e dados como coordenadas, preços, contatos, horários, acessos e infraestrutura só devem ser apresentados como confirmados após verificação em fontes confiáveis.

## Publicação
O workflow em `.github/workflows/pages.yml` instala as dependências, executa o build e tenta publicar o resultado no GitHub Pages.
