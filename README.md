# SOL & ÁGUA BRASIL

Guia independente, em português, para descobrir destinos de natureza e turismo no Brasil.

## Site publicado

https://edoliveiras.github.io/Sol-e-agua-/

## O que o site oferece

- Busca por nome do atrativo, cidade, estado e região.
- Filtros para praias, cachoeiras, day use, hospedagens e favoritos.
- Favoritos salvos no próprio navegador/dispositivo.
- Acesso ao Google Maps para localizar os destinos.
- Consulta de previsão do tempo de até 7 dias por cidade, usando Open-Meteo.
- Guia complementar por destino com links para atrações, alimentação, vida noturna, hospedagem, mobilidade e informações de segurança.
- Calendário selecionado de festas e eventos de Minas Gerais.
- Layout adaptado para celular e computador.

## Situação do catálogo

O catálogo está em expansão e não deve ser interpretado como inventário completo de todos os destinos brasileiros. A base contém registros de praias e cachoeiras de diferentes estados, além de seleções de day use, hospedagens e eventos. A quantidade e a cobertura variam conforme as pesquisas e atualizações realizadas.

As fotografias também têm níveis diferentes de verificação: algumas são imagens ilustrativas; outras são fotos específicas do atrativo com identificação e crédito. O próprio site sinaliza quando uma foto específica ainda está em revisão. Não atribua uma foto ilustrativa a um lugar como se fosse uma imagem documental dele.

## Cuidados e transparência

- Informações de acesso, preços, horários, regras, eventos e funcionamento podem mudar. Confirme sempre com a prefeitura, unidade de conservação ou operador responsável antes de viajar.
- A previsão do tempo é aproximada para a região da cidade, não uma medição exata na praia ou cachoeira. Consulte também alertas meteorológicos oficiais.
- Condições de banho, correnteza, maré, nível dos rios, trilhas e segurança mudam rapidamente. Nunca entre na água sob alerta de chuva forte, trovoadas ou risco de cabeça d'água.
- Links de pesquisa ajudam a encontrar informações locais, mas não significam que cada estabelecimento tenha sido verificado individualmente.
- O projeto é independente e não substitui orientações de autoridades, guias credenciados ou responsáveis pelos atrativos.

## Tecnologia e publicação

O projeto é uma página estática em HTML, CSS e JavaScript, publicada pelo GitHub Pages por meio de GitHub Actions. Não exige cadastro nem coleta dados em servidor; a lista de favoritos fica no armazenamento local do navegador.

## Como contribuir

Sugestões de destinos, correções, fotos com licença aberta e informações oficiais são bem-vindas. Para cada fotografia reutilizada, devem ser preservados o nome do autor, a licença e o link da fonte.
