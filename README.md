# SOL & ÁGUA BRASIL

Guia visual para descobrir praias e cachoeiras do Brasil.

## Como abrir
O site é uma página estática: abra `index.html` no navegador ou publique pelo GitHub Pages.

## Recursos
- Busca por destino, cidade e estado
- Filtros de praias e cachoeiras
- Favoritos salvos no próprio dispositivo
- Links para abrir a localização no Google Maps
- Layout adaptado para celular e computador

## Conteúdo
Os destinos iniciais são demonstrativos. Antes de viajar, confirme acesso, condições climáticas, segurança, regras locais e funcionamento com fontes oficiais.
